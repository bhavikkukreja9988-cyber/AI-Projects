# Premiere Media Ingest V6.0.1

Latest release.

V6.0.1 contains two fixes documented in `CHANGELOG.md`:
- ExtendScript-compatible track selection fix for the `vOrder.indexOf` insertion failure.
- Removal of `--restrict-filenames` so downloaded project names preserve titles more faithfully while remaining Windows-safe.

Upload the complete V6.0.1 source under `source/` and the built ZXP installer under `dist/`.
