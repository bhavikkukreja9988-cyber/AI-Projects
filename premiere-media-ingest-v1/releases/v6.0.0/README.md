# Media Ingest V6.0.0

Latest supplied release build.

## Release contents
- `source/` — extracted V6.0.0 project source
- `dist/MediaIngest-V6.0.0.zxp` — ready-to-install CEP package
- `CHANGELOG.md` — V6.0.0 changes and testing notes

## Important
V6.0.0 is a UI rebuild based on the working V5.4.6 source. The download/history/codec pipeline and the V5.4.6 Stack-insertion track-search fix are intended to remain unchanged. The supplied changelog records the exact scope and test results.

## Manual upload
The repository connector cannot upload binary ZIP/ZXP files directly. Upload the extracted source files into `source/` and the `.zxp` installer into `dist/` from GitHub's web interface.
